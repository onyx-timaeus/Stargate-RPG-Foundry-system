# NPC compendium image prompts
Same workflow as `icon-prompts.md`: new ChatGPT image chat, paste the **Master style** once, then one **batch** at a time. Save each sheet as `npcs-batch-<nn>.png` and send them over. I slice them into `assets/compendium/npcs/_<group>.webp` (the build picks them up automatically, also as token image). 24 portraits cover all 340 NPCs; a single entry can still get its own picture later by naming it after the entry (e.g. `cr2-recruit.webp`).
All subjects are from the Stargate SG-1 universe (TV series and RPG).

## Master style (paste first)

```
Character portrait, 1:1 square, 512x512, head-and-shoulders bust centered and filling about 80% of the frame, painterly semi-realistic digital style with clean edges, dramatic rim lighting, slightly desaturated military sci-fi palette with one accent colour per portrait, dark neutral vignette background (no scene, no border, no frame), no text, no letters, no numbers, no watermark.
I will give you batches. For each batch create ONE image: a grid of separate portraits with equal spacing and thin dark gutters, reading order left to right, top to bottom. Same style, lighting and camera angle for all portraits so they look like one set. Do not write names into the image. People are generic and not based on real actors.
```
