# NPC compendium: sources and decisions
Pack `npcs` (Actor). Source JSON is generated from the Core Rulebook v1.03 (see git history for the generator notes); compile with `npm run packs:build`.

- Class NPCs (120): pp. 323-346, statblocks as printed. CR is the printed CR (level 1 = CR 1/2, level 20 = CR 19). Names and CRs are the statblock headings. Scout "Pioneer" is printed as level 7 twice; it is level 6. Soldier statblocks use different names than the NPCs-by-class table (Town Guard, Pikeman, Brute, Wild Barbarian vs. Cadet, Infantry, Trooper, Marine) and Town Guard is CR 1 while the other classes start at CR 1/2.
- Jaffa: `Example Troops` has the 12 named statblocks from pp.306-308 (Recruit CR1, Rookie Pilot CR3, Guard CR4, Shock Troop CR5, Veteran CR7, Jaffa Ninja CR9, Vanguard CR10, Veteran Pilot CR11, Chosen CR13, Ace Pilot CR15, Exalted CR16, Failed Prime CR20). `Base Statblocks` has the 20 generic rows from the Jaffa Attributes table p.303 (one per CR, "CR n: Jaffa Troop"); skills (2 + 1 at CR 3/9/15) and feats (2 x CR MP) are left to the GM.
- Beasts (16): only the example beasts printed in the book (pp.314-317), in one folder per beast type: Surly Kitten CR1/8, Trash Panda CR1/4, Grass Snake CR1/2, Hungry Vulture CR1, Nope-Nope Spider CR2, Junk Yard Dog CR3, Ravenous Piranhas CR4, Abydonian Lizard CR4, Flanged Orangutan CR5, Jungle Anaconda CR6, Dairy Cow CR7, Mastadge CR8, Reef Shark CR9, Velociraptor CR10, Bird of Prey CR11, Draft Horse CR12. No blank CR x type templates; beast abilities are copied from the Hub builder text.
- Ashrak p.309, un-hosted Goa'uld p.302 (no attributes in the book, all 10), Replicators pp.318-319 (5), Reetou Rebel p.320. Tok'ra: no statblock in the book, folder is empty. Homebrew: empty.
- Attack rolls: the sheet rolls d20 + ability mod + attack bonus (+ proficiency when the weapon's proficiency type is ticked on the actor). Each attack uses the ability whose modifier matches the printed damage bonus. Where the NPC is proficient with the weapon type, the weapon carries the proficiency type and the attack bonus is the printed to-hit minus modifier minus proficiency; otherwise the proficiency is folded into the attack bonus.
- Proficiencies: class NPCs get their class's armor, weapon and tool proficiencies (plus Heavy Armor / weapon Proficiency feats from the statblock). Jaffa get Jaffa and common weapons, light armor, and heavy armor from CR 13. Ashrak: common and Jaffa weapons, light and heavy armor. Where a printed skill value is above modifier + proficiency (expertise), the GM notes list it, because the sheet recalculates skills as modifier + proficiency.
- Feats and abilities are copied from the feats and class-abilities packs. Name differences resolved: Calm & Collected = Calm and Collected, A Word in an Ear = Word in an Ear, Heavy Armor Training = Heavy Armor Proficiency, Steady Aim = Steady Arm, Board-Spectrum Scanners = Broad Spectrum Scanners, Longarms Calibrations = Longarm Calibrations, "Proficiency (x)" = Skill/Weapon Proficiency.
- Not in the feats pack (added by name only, text "See Core Rulebook"): Botanist, Contortion, Inspiration, Longarms Maintenance, Resonate Words, Weapon Mastery (common), Advanced.
