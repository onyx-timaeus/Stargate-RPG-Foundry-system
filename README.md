# Stargate RPG – Foundry VTT System

A game system for [Foundry VTT](https://foundryvtt.com) (v13) for the **Stargate SG-1 Roleplaying Game**.

The rules are made by **Wyvern Gaming**.

This system does not include the rulebook. You need your own copy to play.

## Features
* Player and NPC sheets with an inventory tab, damage resistances and a configuration tab
* Weapons, equipment, origins, class abilities and feats as items, with compendiums
* Roll cards for attacks, damage and checks, item "send to chat" cards, dice animation support
* Death saves, alive/dead status and optional whispered rolls (GM and owner only)

## Installation
Paste this URL into the *Install System* dialog on the Setup menu of Foundry VTT:

`https://raw.githubusercontent.com/onyx-timaeus/Stargate-RPG-Foundry-system/master/system.json`

To install manually, clone or extract this repository into `Data/systems/sgrpg`.
